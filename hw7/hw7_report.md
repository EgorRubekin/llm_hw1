# Квантизация и hard-label дистилляция Qwen3 на MASSIVE ru-RU

Источник: собственные сохранённые predictions и исходный код пользователя. Метрики ниже пересчитаны из JSONL; чужие результаты не использованы.

## Протокол
Baseline/ученик: Qwen3-8B; учитель: Qwen3-32B. Dev: 256 фиксированных примеров validation, seed=42. Это подвыборка dev, не весь split. Train используется для калибровки и hard labels; test не используется. Quality = (Intent Accuracy + Slot Micro F1) / 2. Slots — мультимножество нормализованных пар; схема JSON проверяется строго. Генерация greedy, thinking выключен, лимит ответа 128 токенов.
Оценка квантизированных весов проводится через Transformers в bf16 после распаковки. Это измерение качества квантованной сетки, а не ускорения int4-инференса. SmoothQuant сохраняется в dense-формате с W8A8 fake quantization и динамическим квантованием активаций по токенам: это обход ошибки загрузки int8-параметров в Transformers 4.55.2. Размер его файла не показывает степень сжатия.

## Квантизация

AWQ MASSIVE и WikiText: W4A16 asymmetric, group_size=128, 128 примеров, lm_head в исходной точности. Различается только источник калибровки, оба источника проходят через один chat template. WikiText берётся из train; длины текстов могут отличаться, поэтому эффект относится к корпусу вместе с его распределением длин.
GPTQ: W4A16 symmetric, group_size=128, 128 примеров MASSIVE. SmoothQuant: W8A8 с QuantizationModifier, smoothing_strength=0.5, 128 примеров MASSIVE. Это сравнение конфигураций, оно не позволяет отдельно оценить причинный эффект метода и битности.

Разность Quality AWQ MASSIVE − WikiText: -0.004564. На этой подвыборке выше WikiText.

## Дистилляция

Обучение только на валидных сгенерированных ответах учителя; gold не подмешивается. Prompt и padding маскируются -100. LoRA r=16, alpha=32, dropout=0.05, все attention/MLP projections; batch=1, accumulation=8, bf16, gradient checkpointing. После обучения адаптер объединяется с базовой моделью.
Три запуска: 512 / lr=1e-4 / 1 epoch; 512 / lr=5e-5 / 1 epoch; 1024 / lr=5e-5 / 2 epochs. Первые два изолируют learning rate. Третий одновременно увеличивает данные и число эпох; разделить их вклад по нему нельзя. Выбор лучшего по dev оптимистичен: независимая итоговая оценка здесь не проводилась.

Лучший ученик: sft_n1024_lr5e-05_ep2. Quality=0.605893; порог 90% учителя=0.521404; достигнут: True. Превосходит baseline: True.

Снижение lr при 512 примерах и одной эпохе меняет Quality на -0.018975. Увеличение данных и эпох при lr=5e-5 меняет Quality на +0.060302.
